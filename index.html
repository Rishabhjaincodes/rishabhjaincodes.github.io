MeshSOS

Feb 2026 — present

Java · Android SDK · Bluetooth Low Energy · SQLite · Firebase

  • Native Android app that relays distress messages device to device over BLE, staying fully functional with no cellular or Wi-Fi connectivity.
  • Implemented BLE advertising and scanning with a custom packet format and TTL-based forwarding, so a message hops onward instead of dying at the first out-of-range device.
  • Offline-first SQLite layer queues GPS coordinates and payloads locally, then syncs to Firebase on reconnect — no message is lost while the network is down.
